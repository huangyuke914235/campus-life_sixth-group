# 设计规范（DESIGN SYSTEM）

> 本文档定义视觉语言与组件约定。改 UI 前先读，避免风格漂移。
> 真实值来自 `apps/web/tailwind.config.ts` 与 `apps/web/src/app/globals.css`。

---

## 一、设计理念

**一句话**：让校园食堂工具**不像后台管理系统**。

三条原则：

| 原则 | 具体做法 |
|---|---|
| **暖** | 底色不是纯白，是米白 `#FFFBF5`；主色是橙不是蓝；大面积留白但不死板（body 带极淡双色径向渐变） |
| **轻** | 圆角 18px、阴影极淡（`0 8px 24px rgba(37,41,35,0.08)`），不用硬边框分块 |
| **实** | 所有视觉元素都指向"吃"：菜品图、价格、档口位置。不做纯装饰的渐变球和光晕 |

**反面参考**：Ant Design 默认风格（蓝主色 + 直角 + 密集信息）——那是效率工具，不是生活工具。

## 二、色彩系统

### 2.1 亮色（默认）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FFFBF5` (cream) | 页面底色 |
| `--surface` | `#FFFFFF` | 卡片、输入框 |
| `--surface-soft` | `#F7F2E9` (beige) | 次级背景、hover |
| `--text` | `#252923` (ink) | 正文、标题 |
| `--muted` | `#6B7167` | 辅助说明、时间戳 |
| `--line` | `#EDE6DA` | 分隔线、边框 |
| `--accent` | `#FF8A4C` (orange) | **主色**：按钮、强调数字、选中态 |
| `--accent-deep` | `#E96F35` | 主色按压态、链接 |
| `--positive` | `#4F7D61` (sage deep) | 好评、营养达标、成功提示 |

**辅助色**：
- `sage` `#78A68A`：素食、清淡标签
- `sage-light` `#E7F1EA`：素食标签底
- `orange-light` `#FFE7D6`：主色标签底

### 2.2 暗色

由 `.dark` 类切换，全部变量有对应暗色值：

| Token | 暗色值 |
|---|---|
| `--bg` | `#1C201B` |
| `--surface` | `#262B24` |
| `--surface-soft` | `#2F362D` |
| `--text` | `#F5F1E8` |
| `--muted` | `#A9B2A4` |
| `--line` | `#3A4237` |
| `--accent` | `#FF9A62`（暗色下更亮，保证对比度） |
| `--positive` | `#8FC4A2` |

### 2.3 用色纪律

| 规则 | 说明 |
|---|---|
| 主色**只用于可交互元素** | 按钮、链接、选中态。不用来装饰标题 |
| 同一屏最多 **2 个强调色** | 橙 + 绿。多了显乱 |
| 价格用 `--accent-deep` | 保持"贵/便宜"的视觉联想 |
| 评分色阶 | 差 1–3 用红、一般 4–7 用 muted、好评 8–10 用 `--positive` |
| **不要**用纯红做错误 | 用 `--accent-deep` + 文字说明，避免刺眼 |

## 三、字体与字号

**字体栈**：`'Noto Sans SC', Inter, system-ui, sans-serif`

**为什么不用系统默认**：中文字体在 Windows 上默认是宋体/雅黑，观感偏"办公软件"。Noto Sans SC 字重均匀，更接近移动端 App 的质感。

### 字号阶梯

| 场景 | 类 | 大小 |
|---|---|---|
| 页面主标题 | `text-2xl font-bold` | 24px |
| 卡片标题 | `text-sm font-bold` | 14px |
| 正文 | `text-sm` | 14px |
| 辅助说明 | `text-xs` | 12px |
| 极小字（时间戳、标签） | `text-[11px]` | 11px |
| 强调数字 | `text-lg font-bold` | 18px |

**行高**：正文 `leading-5`（20px），长段落 `leading-6`

**字重**：只用 400（常规）和 700（粗体），不用 500/600——避免中文字重在部分系统上渲染不一致。

## 四、形状与间距

| Token | 值 | 用途 |
|---|---|---|
| `rounded-card` | 18px | 卡片、大容器 |
| `rounded-pill` | 24px | 按钮、标签 |
| `rounded-xl` | 12px | 小卡片、提示条 |
| `shadow-soft` | `0 8px 24px rgba(37,41,35,0.08)` | 卡片浮起 |
| 卡片内边距 | `p-4` / `p-5` | 16px / 20px |
| 元素间距 | `gap-2` / `gap-3` | 8px / 12px |
| 区块间距 | `mt-5` / `mt-6` | 20px / 24px |

**布局约束**：
- 移动端优先，主容器 `max-w-md`（448px）
- 桌面端居中，不拉满屏（阅读舒适区）
- 底部导航固定，内容区留 `pb-20` 防遮挡

## 五、组件约定

### 5.1 卡片（`sg-card`）

```tsx
<article className="sg-card p-4">...</article>
```

- 白底 + 18px 圆角 + 极淡阴影
- **不用边框**（边框显硬）
- hover 时 `translate-y-[-1px]`（轻微上浮，不放大）

### 5.2 按钮

| 类型 | 类 | 用途 |
|---|---|---|
| 主按钮 | `bg-orange text-white rounded-pill px-5 py-2.5` | 页面唯一主动作 |
| 次按钮 | `bg-white border border-line text-ink rounded-pill` | 次要操作 |
| 文字按钮 | `text-orange-deep text-xs` | 跳转、更多 |
| 危险操作 | `text-red-600` + 二次确认 | 取消订单、删除 |

**纪律**：一屏只允许**一个**主按钮。

### 5.3 标签（chip）

```tsx
<button className="rounded-pill px-3 py-1.5 text-[11px] bg-surface-soft">想吃辣</button>
```

- 未选中：`bg-surface-soft text-muted`
- 选中：`bg-orange text-white`
- 高度统一 28px，横向可滚动（`sg-scroll` 隐藏滚动条）

### 5.4 输入框

- 高度 44px（移动端可点区）
- 圆角 12px
- focus 时边框变 `--accent`，**不加 box-shadow 光晕**
- 错误态：边框变红 + 下方 11px 红字

### 5.5 骨架屏

`sg-skeleton`：淡米色底 + 呼吸动画。**加载超过 300ms 才显示**，避免闪烁。

## 六、页面布局模式

### 6.1 首页（推荐）

```
┌─────────────────────┐
│ 顶部问候 + 时段切换   │
├─────────────────────┤
│ 推荐卡 ×3（含理由）    │  ← 视觉重心，占 60% 高度
├─────────────────────┤
│ 快捷入口（菜单/评价）  │
├─────────────────────┤
│ 今日菜单与食堂        │
├─────────────────────┤
│ 底部导航              │
└─────────────────────┘
```

**层级纪律**：首页只回答一个问题——**今天吃什么**。所有其他入口都是次级。

### 6.2 列表页（菜单 / 评价）

- 顶部筛选条（横向滚动 chip）
- 内容区 2 列网格（移动端）/ 3 列（桌面）
- 底部「加载更多」

### 6.3 详情页（菜品）

- 大图（16:9）
- 标题 + 价格 + 档口位置
- 三个维度条（辣度/油腻/咸度，0–5）
- 营养成分表
- 评价列表
- 底部固定「加入购物车」

## 七、菜品图片映射

**当前策略**：**不上传实拍图**，按菜名关键词映射到 12 张分类图。

实现：`apps/web/src/lib/dish-image.ts`

| 关键词 | 映射图 |
|---|---|
| 米线 / 粉 / 面 | `noodles.jpg` |
| 烧腊 / 鸭 / 叉烧 | `roast.jpg` |
| 鱼 / 酸菜鱼 | `fish.jpg` |
| 鸡 / 黄焖鸡 | `chicken.jpg` |
| 牛 / 牛肉 | `beef.jpg` |
| 猪 / 小炒肉 | `pork.jpg` |
| 汤 / 粥 | `soup.jpg` |
| 蔬菜 / 素 | `veggie.jpg` |
| 麻辣 / 辣 | `spicy.jpg` |
| 早点 / 包 | `breakfast.jpg` |
| 饮 / 奶茶 | `drink.jpg` |
| 默认 | `default.jpg` |

**为什么这么做**：
- 商户拍照质量参差，实拍图反而拉低观感
- 12 张高质量分类图保证视觉一致性
- 未来要换成实拍，只需在 `dish.imageUrl` 有值时优先用该字段（已预留）

## 八、可访问性与细节

| 项 | 要求 |
|---|---|
| 对比度 | 正文与背景 ≥ 4.5:1；`--muted` 只用于 12px 以下的次要信息 |
| 点击区 | 移动端 ≥ 44×44px |
| 焦点态 | 键盘 Tab 可见 `ring-2 ring-orange` |
| 动效 | 最多 200ms；`prefers-reduced-motion` 时关闭 |
| 图标 | 统一用 `lucide-react`，尺寸 12/16/20 三档 |
| 空状态 | 必须给"下一步做什么"，不能只写"暂无数据" |

**文案纪律**：
- 不用"亲""小可爱"等卖萌词
- 错误提示写**原因 + 怎么办**（"库存不足，换一道或换档口"）
- 推荐理由必须**引用具体数字**（"18 元，在你设的 15–25 元内"）

## 九、改 UI 时的检查清单

- [ ] 新颜色是否用了已有 token（不要新增十六进制值）
- [ ] 主按钮是否只有一个
- [ ] 移动端 375px 宽度下是否溢出
- [ ] 暗色模式下是否可读（切 `.dark` 类看一遍）
- [ ] 加载态 / 空态 / 错误态是否都有
- [ ] 文案是否指向上一步的原因和下一步的动作
