# 用户手册

## 学生

**1. 登录**：`/login`，演示环境可一键填入演示邮箱；密码由部署方提供。

**2. 完成口味问卷**：首次使用进入偏好设置，用标签与滑块填写菜系、主食、食材、辣度、油盐甜、预算、忌口与过敏原、饮食模式。
> 过敏原与忌口为**硬性过滤**，之后任何推荐都不会出现；系统推断永远不会覆盖你手动设置的内容。

**3. 今天吃什么**：首页点「帮我选这一餐」，可加「想吃辣 / 清淡一点 / 高蛋白 / 尝新」等情境。结果给 3 道菜，每道都有匹配度与**来自你真实数据的理由**；点「推荐依据」可看权重与各维度得分。
> 匹配度是算法估算排序结果，不是精确概率。

**4. 点餐与取餐**：选菜加入清单 → 选档口与取餐时段 → 确认下单。一个订单只能含同一档口（跨档口请分开下单）。到店出示取餐码或二维码，由档口核销。

**5. 饭后 10 秒反馈**：订单完成后点「评价这一餐」——点星星、选几个体感标签、可选写一句话，提交即可。
> 体感标签会真实影响下次推荐：比如选「有点油腻」，高油腻度相似菜品会被降权。评分可事后修改。

**6. 越来越懂你**：个人页查看看板式的口味画像，区分「我设置的」与「系统推断」；可一键重置推断，不影响你设置的忌口。

**7. 隐私**：账号可申请停用并撤销登录态；订单与评价作为审计记录按规留存。

## 商户

登录后进入订单操作台：接单 → 备餐 → 待取餐 → 核销；可维护菜品（价格/食材/标签/营养/库存/上下架）、发布每日菜单、复制昨日菜单、配置取餐时段与容量。
> 只能操作被授权的档口，越权请求会被后端拒绝。

评价分析页可看均分分布、体感反馈占比；**样本不足 5 条时不会自动生成经营建议**。

## 管理员

用户与角色管理、食堂与档口管理、评价审核（仅影响展示，不改统计与画像）、公告发布、订单监督、平台看板与操作日志。

## 演示环境声明

- 支付为**到店付款演示模式**，未接入真实支付 / 校园一卡通。
- 营养数值为**示例估算**，不是实验室检测结果，不用于医疗建议。
- 菜品图片为演示占位素材。
- 主观体感不构成医学判断；过敏原信息以食堂公示为准，存在交叉接触风险。
